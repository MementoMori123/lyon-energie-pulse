# Lyon Énergie Pulse ⚡️

**English:** An open-source real-time dashboard monitoring the electricity consumption and local renewable production of the Lyon Metropolitan area. Built with Python (FastAPI) and Open Data from RTE.

**Français:** Un tableau de bord open-source surveillant en temps réel la consommation électrique et la production renouvelable locale de la Métropole de Lyon.

## 🚀 Quick Start
1. `source venv/bin/activate`
2. `pip install -r requirements.txt`
3. `python main.py`
